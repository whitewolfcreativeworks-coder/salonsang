Salon Sang

iPhone setup

Three little things and your iPhone does the rest: it puts the portal on your home screen, alerts you about new bookings, and sends your clients' texts from your own number.

1 · Put the portal on your home screen

1
Open salonsang.com/portal in Safari and sign in.
2
Tap the Share button (the square with the arrow), then Add to Home Screen → Add.
3
Now it opens like an app, with your pink Salon Sang icon 💖

2 · New-booking alerts (free ntfy app)

1
Install ntfy from the App Store (free, by Philipp Heckel). Allow notifications.
2
In the portal, open Settings → Your iPhone and tap Alert topic to copy it.
3
In ntfy tap ＋, paste the topic, keep the server ntfy.sh, tap Subscribe.
4
That's it: every online booking pings you instantly, and you get a little good-morning summary of your day ☀️

3 · Client texts from your number (Shortcuts)

This shortcut asks the portal “any texts due?”, sends each one from your Messages, and marks it sent. You'll build it once (about 10 minutes), then add hourly automations so it runs by itself.

A. Build the shortcut in the Shortcuts app → ＋ → name it Salon Sang texts:

1
Add Get Contents of URL. URL: the Shortcut address from portal Settings. Tap Show More: Method POST. Headers: apikey = the Site key, Content-Type = application/json. Request Body JSON: add a Text field p_token = your secret phone key.
2
Add Repeat with Each (item in Contents of URL).
3
Inside the repeat, add Get Dictionary Value → Value for text in Repeat Item.
4
Add Get Dictionary Value → Value for phone in Repeat Item.
5
Add Send Message: message = the text value, recipient = the phone value. Tap the arrow and turn Show When Run off.
6
Add Get Dictionary Value → Value for id in Repeat Item.
7
Add Get Contents of URL with the same address but ending in phone_sent instead of phone_outbox, same headers, Method POST, JSON body: p_token = your key, and a Number field p_id = the id value.
8
Tap ▶︎ once to test. With nothing due it simply finishes quietly.

B. Make it run by itself, every hour while you work:

1
Shortcuts → Automation → ＋ → Time of Day → 8:00 AM, Daily.
2
Choose Run Immediately (and turn off Notify When Run), then pick Salon Sang texts.
3
Repeat for 9 AM, 10 AM … through 7 PM (12 little automations). Reminders go out about 4 hours before each appointment, never before 8 AM.

Keep your phone on and charged during the day 💡 If it ever misses a text, the portal's Today screen shows a Send button next to anything waiting, so you can send it with one tap.
